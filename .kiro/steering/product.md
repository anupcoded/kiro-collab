# Product

A micro-blogging social media application. Users register and log in, create short text posts (280 character limit), browse a feed, like posts, and follow/unfollow other users. Each user has a profile they can view and edit.

## Core Features
- Authentication: register, login (AWS Cognito-backed)
- Posts: create, read (feed with pagination + sort by newest/popular), update, delete, like/unlike
- Users: view profile, update profile, follow/unfollow, check following status

## Design Aesthetic
Modern, social-media-inspired look with a purple (#8b5cf6) and white theme, rounded elements, and a mobile-first responsive layout. See `DESIGN_LANGUAGE.md` for the full design system (colors, typography, spacing, components). Follow it when building or changing UI.
